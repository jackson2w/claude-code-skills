# New Site Reference

## Project Scaffold

Every new project gets this exact directory structure:

```
{project-slug}/
├── src/
│   ├── _includes/
│   │   ├── base.njk          ← base HTML shell (head, scripts, analytics hook)
│   │   ├── nav.njk           ← site navigation
│   │   └── footer.njk        ← site footer
│   ├── _data/
│   │   └── site.js           ← global site metadata (name, url, description)
│   ├── css/
│   │   ├── grt.css           ← generated by GRT calculator — never hand-edit
│   │   └── style.css         ← project styles, imports grt.css
│   ├── images/               ← WebP images go here (see performance.md)
│   ├── fonts/                ← self-hosted fonts if any
│   └── index.njk             ← home page
├── public/
│   └── _headers              ← Cloudflare cache rules (see performance.md)
├── .gitignore
├── .eleventy.js              ← 11ty config
├── package.json
└── wrangler.toml             ← Cloudflare Pages config (see deploy.md)
```

Additional pages go in `src/` as `.njk` or `.md` files. 11ty infers URL from filename.

## .eleventy.js (Standard Config)

```js
module.exports = function(eleventyConfig) {
  // Pass through static assets
  eleventyConfig.addPassthroughCopy("src/css");
  eleventyConfig.addPassthroughCopy("src/images");
  eleventyConfig.addPassthroughCopy("src/fonts");
  eleventyConfig.addPassthroughCopy("public");

  // Watch CSS for changes in dev
  eleventyConfig.addWatchTarget("src/css/");

  return {
    dir: {
      input: "src",
      output: "_site",
      includes: "_includes",
      data: "_data"
    },
    templateFormats: ["njk", "md", "html"],
    markdownTemplateEngine: "njk",
    htmlTemplateEngine: "njk"
  };
};
```

## Base Template (src/_includes/base.njk)

```html
<!DOCTYPE html>
<html lang="en" class="grt">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="{{ description or site.description }}">
  <title>{% if title %}{{ title }} — {% endif %}{{ site.name }}</title>

  <!-- Canonical -->
  <link rel="canonical" href="{{ site.url }}{{ page.url }}">

  <!-- Open Graph -->
  <meta property="og:title" content="{{ title or site.name }}">
  <meta property="og:description" content="{{ description or site.description }}">
  <meta property="og:url" content="{{ site.url }}{{ page.url }}">
  <meta property="og:type" content="website">

  <!-- Fonts (update per project) -->
  <!-- <link rel="preconnect" href="https://fonts.googleapis.com"> -->

  <!-- Styles -->
  <link rel="stylesheet" href="/css/grt.css">
  <link rel="stylesheet" href="/css/style.css">
</head>
<body>
  {% include "nav.njk" %}
  <main>
    {{ content | safe }}
  </main>
  {% include "footer.njk" %}
</body>
</html>
```

## Design Direction

When Will provides aesthetic direction, commit fully to it. Ask if not provided:

> "What's the aesthetic? Options: editorial/magazine, luxury/refined, brutalist/raw,
> warm/professional, minimal/clean, bold/expressive — or describe what you have in mind."

Once chosen, select fonts accordingly. Never use Inter, Roboto, or Arial. Prefer:
- Editorial: Playfair Display + Source Serif Pro, or DM Serif Display + Lora
- Luxury: Cormorant Garamond + Jost, or Canela + Aktiv Grotesk
- Minimal: Instrument Serif + DM Sans, or Fraunces + Inter (Inter acceptable here only as body)
- Bold: Bebas Neue + Space Mono, or Syne + Epilogue
- Warm/Professional: Libre Baskerville + Nunito Sans, or Merriweather + Work Sans

Font choices feed into GRT's x-height correction (see typography.md):
- Georgia, Merriweather, Lora: x-height ≈ 0.49–0.52
- Playfair Display: x-height ≈ 0.47
- Most sans-serifs: x-height ≈ 0.52–0.55

## CSS Architecture

`style.css` imports GRT and adds project-specific styles. Structure:

```css
@import url('./grt.css');

/* ── Custom Properties ─────────────────────────── */
:root {
  --color-bg: #fff;
  --color-text: #1a1a1a;
  --color-accent: #c45c2e;
  /* ... */
}

/* ── Reset ─────────────────────────────────────── */
*, *::before, *::after { box-sizing: border-box; }
body { margin: 0; background: var(--color-bg); color: var(--color-text); }
img { max-width: 100%; height: auto; display: block; }

/* ── Layout ─────────────────────────────────────── */
/* ... */

/* ── Components ──────────────────────────────────── */
/* nav, hero, cards, footer, etc. */

/* ── Utilities ───────────────────────────────────── */
/* ... */
```

Use GRT variables throughout — never hardcode font sizes or line heights:
```css
/* Never */
h1 { font-size: 42px; line-height: 1.2; }

/* Always */
h1 { font-size: var(--grt-h1-size); line-height: var(--grt-h1-lh); }
```

## Image Script (scripts/images.js)

```js
const sharp = require('sharp');
const fs = require('fs');
const path = require('path');

const SRC = path.join(__dirname, '../src/images');
const DEST = path.join(__dirname, '../_site/images');

// Ensure output dir exists
fs.mkdirSync(DEST, { recursive: true });

// Convert all jpg/png to WebP non-destructively
fs.readdirSync(SRC).forEach(file => {
  const ext = path.extname(file).toLowerCase();
  if (!['.jpg', '.jpeg', '.png'].includes(ext)) return;

  const name = path.basename(file, ext);
  const input = path.join(SRC, file);
  const output = path.join(DEST, `${name}.webp`);

  sharp(input)
    .webp({ quality: 85 })
    .toFile(output)
    .then(() => console.log(`✓ ${file} → ${name}.webp`))
    .catch(err => console.error(`✗ ${file}: ${err.message}`));
});
```

Originals in `src/images/` are never modified. WebP derivatives land in `_site/images/`.
Reference all images in HTML as `/images/{name}.webp`.
